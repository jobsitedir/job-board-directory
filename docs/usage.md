# Using the files

Open data/<domain>.json or read it with your JSON parser. Image paths are relative to that JSON file. Download the versioned source archive from Releases to preserve the exact selection used in your research.

Run `node scripts/validate.ts` with Node.js 24 or later to check the files locally. No account or external API is needed.
